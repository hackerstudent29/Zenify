## 🔍 Deep Dive (for the curious)

<details>
<summary><b>🎵 Audio architecture &amp; anti-snippet policy</b></summary>
<br />

* **Zero 30-second previews** — iTunes/Apple preview URLs are banned by design. Every track resolves to a full-length stream via 320 kbps Akamai CDN or full YouTube audio.
* **Dual-ExoPlayer overlap** — two synchronized ExoPlayer instances (`player` and `fadePlayer`, in `ZenAudioPlugin.kt`) enable zero-gap playback, pre-warming and smooth crossfades.
* **Bitrate profiles** — `320 kbps` (Pristine), `160 kbps` (Opus), `128 kbps` (AAC), `70 kbps` (Data Saver).
* **Volume normalization (-14 LUFS)** — uses loudness metadata to even out volume between songs from different eras.
* **Stereo-to-mono downmix** — an accessibility option so single-earbud listeners never lose panned instruments or backing vocals.

</details>

<details>
<summary><b>🎛️ All 20 DJ crossfade styles</b></summary>
<br />

| Category | Style | What you'll hear |
|---|---|---|
| **Auto** | `Auto Intelligent Blend` | Analyzes BPM, energy, silence and key of both tracks and picks the best transition |
| **Classic** | `Smooth Crossfade` | Equal-power crossfade with steady loudness |
| | `Classic Linear` | Symmetrical linear volume taper |
| | `Cinematic S-Curve` | Gentle lead-in, gradual fade-out |
| | `Fade Through Dip` | A brief dip to silence for dramatic pacing |
| **DJ Blend** | `DJ Blend` | Club-style blend with a gradual high-frequency wash |
| | `Bass Swap` | Outgoing bass drops out at the midpoint while the incoming bassline kicks in |
| | `Filter Sweep` | Low-pass sweep out, high-pass sweep in |
| | `Stutter Gate` | Tempo-synced 8th-note chopping |
| | `Slam Cut` | Instant beat drop on the next downbeat |
| | `Riser` | Snare-roll riser into the drop |
| **Production** | `R&B Glide` | Pitch-glide vinyl-style vocal blend |
| | `Echo Out` | Outgoing audio freezes into a delay tail |
| | `Reverb Wash` | Song washes into a cathedral reverb tail |
| | `Tape Stop` | Analog tape machine powering down |
| | `Vinyl Brake` | Turntable brake and tonearm scratch |
| | `Spin-Up` | Turntable spinning up from a dead stop |
| | `Lo-Fi Dive` | Bitcrusher hold and filter dive to 8-bit texture |

Test transitions on real song pairs in *Settings → Crossfade* before you listen.

</details>

<details>
<summary><b>🎚️ Studio FX details</b></summary>
<br />

* **Parametric EQ** — Low Shelf (32Hz–250Hz), Peaking Mid (250Hz–4kHz), High Shelf (4kHz–16kHz), ±12 dB.
* **8D Spatial Audio** — orbital rotation using interaural time and intensity differences; speed 0.05–1.0 Hz, clockwise or counter-clockwise.
* **Reverb** — Warehouse and Cathedral with adjustable wet/dry mix.
* **Drive &amp; Warmth** — analog tube saturation for extra punch.
* **Stereo Width &amp; Delay** — widen the soundstage or add echo with custom feedback.
* **Vocal Mode** — boost vocals or reduce them for instant karaoke.
* **Spectrum** — native 36-band FFT analyzer at 30 fps.

</details>

<details>
<summary><b>🎤 Lyrics engine details</b></summary>
<br />

* Parallel racing between `lrc.red` and `lrclib.net` resolves lyrics in under 300 ms.
* Word-by-word glowing karaoke cursor and automated instrumental countdown dots.
* Romanization for Japanese, Korean, Hindi, Tamil, Telugu and more.
* Offline lyrics bundled with downloads.
* Manual timing offset: ±5000 ms in 100 ms steps.

```bash
# 1. Clone the repository
git clone https://github.com/hackerstudent29/Zenify.git
cd Zenify/mobile

flutter pub get

flutter analyze lib/

# 4. Run tests
flutter test test/search_pipeline_test.dart

flutter run
```

**Build release APKs:**

```bash
# Universal release APK
flutter build apk --release

flutter build apk --split-per-abi --release
```

Output files:
* `mobile/build/app/outputs/flutter-apk/app-release.apk` — Universal
