# Zenify Product Roadmap

This document outlines the planned features and improvements for Zenify. Dates are estimates and subject to change based on community feedback and development progress.

---

## 🎯 Current Release

### **v2.5.0** ✅ (2026-02-28)
- Studio FX Glass Panel redesign
- Cleaned settings interface
- Fixed artwork theme application
- Tamil/Hindi/Malayalam synced lyrics
- 3-band EQ + 10+ audio effects
- 8D spatial audio
- Vocal isolation
- Local file playback (MP3, FLAC, WAV, M4A, AAC)
- Full offline PWA support

---

## 📅 Upcoming Releases

### **v2.6** 🔄 (ETA: March 2026)
**Theme**: Multilingual & AI-Powered Lyrics

#### ✨ New Features
- [ ] **Deepgram AI Lyrics** – Automatic lyric alignment with ML precision
- [ ] **More Languages** – Telugu, Kannada, Bengali, Punjabi, Gujarati support
- [ ] **Karaoke Mode** – Full-screen lyrics with adjustable font size
- [ ] **Lyrics Translation** – Auto-translate Indian lyrics to English
- [ ] **Mobile UI Improvements** – Faster, more responsive player on Android

#### 🎨 Improvements
- [ ] Better search results ranking
- [ ] Faster local library indexing
- [ ] Improved artist page layout
- [ ] Playlist sharing (view-only links)

#### 🐛 Bug Fixes
- [ ] Audio context stability on Safari
- [ ] Lyrics sync accuracy improvements
- [ ] Mobile PWA performance optimization

---

### **v2.7** 📅 (ETA: April 2026)
**Theme**: Artist Tools & Community

#### ✨ New Features
- [ ] **Artist Dashboard** – Claim your artist profile, upload artwork, edit bio
- [ ] **Verified Artist Badge** – Green checkmark for verified musicians
- [ ] **Artist Stats** – View your track plays, listener demographics, trending songs
- [ ] **Upload Original Tracks** – Upload your music directly to Zenify
- [ ] **Playlist Collaboration** – Create shared playlists with friends
- [ ] **Advanced Recommendations** – "You Might Also Like" based on listening history

#### 🎨 Improvements
- [ ] Enhanced search with filters (genre, release year, language)
- [ ] Better queue management UI
- [ ] Customizable color themes (beyond dark/light)

---

### **v2.8** 🚀 (ETA: May 2026)
**Theme**: Social & Mobile-First

#### ✨ New Features
- [ ] **Social Sharing** – Share songs, playlists to social media (Instagram, Twitter, WhatsApp)
- [ ] **User Following** – Follow friends, see their playlists
- [ ] **Activity Feed** – See what friends are listening to
- [ ] **Android App v2** – Major Flutter app overhaul with all web features
- [ ] **iOS App** – SwiftUI-based companion app (if licensing allows)
- [ ] **Listening Stats** – Spotify Wrapped-style yearly stats

#### 🔧 Technical
- [ ] GraphQL API (alongside REST)
- [ ] Real-time sync across devices
- [ ] WebSocket support for live updates

---

### **v3.0** 🎉 (ETA: Q3 2026)
**Theme**: Advanced Features & Enterprise

#### ✨ Major Features
- [ ] **Podcast Support** – Stream podcasts in-app
- [ ] **Music Discovery** – AI-powered "Discover Weekly" algorithm
- [ ] **Spatial Audio** – Dolby Atmos-like immersive audio for supported devices
- [ ] **Advanced Audio Analysis** – BPM/key detection, audio fingerprinting
- [ ] **Backup & Sync** – Cloud backup of playlists and preferences
- [ ] **Multi-Device Sync** – Start playing on one device, continue on another
- [ ] **Self-Hosted Option** – Deploy Zenify on your own server (Docker)
- [ ] **API for Third-Parties** – Public API for developers to build on Zenify

#### 🎨 UI/UX
- [ ] Redesigned player interface
- [ ] Customizable widget system
- [ ] Dark mode variants (OLED, dark gray, etc.)

#### 🔒 Enterprise
- [ ] User account protection (2FA)
- [ ] Admin dashboard for enterprise deployments
- [ ] Advanced analytics and reporting

## ❓ Under Consideration

These are ideas we're evaluating but haven't committed to:

- **Spotify/Apple Music Integration** – Direct streaming (licensing complexity)
- **Live Concert Streaming** – Stream concerts in real-time
- **Music Production Features** – In-app DAW (likely out of scope)
- **Blockchain/NFT Integration** – Artist rights verification (research phase)
- **Voice Commands** – "Alexa, play X on Zenify"
