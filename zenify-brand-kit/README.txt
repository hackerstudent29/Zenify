ZENIFY BRAND KIT
================
app-icon/   png (rounded, transparent corners, 16-1024) + square 1024 (no transparency) + svg
ios/        AppIcon.appiconset (drop into Xcode Assets) + AppStore-1024.png (no transparency, no rounded corners)
android/    res/ mipmap folders (ic_launcher, ic_launcher_round), adaptive icon (background, foreground, monochrome + xml), play-store-512.png
macos/      zenify.icns + zenify.iconset (PNG set)
windows/    zenify.ico (16-256 px)
web/        favicon.ico, favicon PNGs, apple-touch-icon, android-chrome, maskable icon, site.webmanifest, head-snippet.html
logo/       transparent/ (color, rose, white, black; 2048/1024/512/128 px)
            solid-background/ (on white, on blush, on ink, white on rose)
            svg/ (vector, scalable)
lockup/     logo + "Zenify" wordmark: transparent/, solid-background/, svg/
social/     avatar (circle + square), og-image 1200x630
colors/     zenify-colors.css
brand-guide/zenify-brand-guide.png

Notes
- The logo mark has real transparent holes for the pads, so it works on any background.
- SVG lockups use the Inter font as live text. Install Inter or convert text to outlines in your design tool.
- Colors: Rose Red #D81B3C, Rose #FB5C74, Blush #FFE3E8, Cream #F3E9EB, Ink #1F1416.
