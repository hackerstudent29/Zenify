## 🐛 Reporting Bugs

### Before You Report
- Check [TROUBLESHOOTING.md](TROUBLESHOOTING.md) (most issues are already solved)
- Check existing [issues](https://github.com/hackerstudent29/Zenify/issues)
- Try clearing cache & reloading
- Test in different browser/device

### How to Report
1. Click [New Issue](https://github.com/hackerstudent29/Zenify/issues/new)
2. Select "Bug Report" template
3. Fill in:
   - **What you were doing** (step by step)
   - **What happened** (actual behavior)
   - **What should happen** (expected behavior)
   - **Browser/device** (Chrome 130 on Windows 11)
   - **Error message** (screenshot or copy from console F12)

### Example Bug Report
```
**What I was doing:**
1. Opened Zenify
2. Searched "Never Gonna Give You Up"
3. Clicked play

**What happened:**
No audio played, no error message

**What should happen:**
Song should play with audio

**Browser:** Chrome 130 on Windows 11
**Error:** (screenshot of console error)
```

**Response time**: 24-48 hours

## 💡 Suggesting Features

### Before You Suggest
- Check [ROADMAP.md](ROADMAP.md) (feature might be planned)
- Check [Discussions](https://github.com/hackerstudent29/Zenify/discussions) (someone might have suggested it)

### How to Suggest
1. Go to [Discussions](https://github.com/hackerstudent29/Zenify/discussions)
2. Click "New Discussion"
3. Select "Ideas" category
4. Describe:
   - **What you want** (the feature)
   - **Why you want it** (problem it solves)
   - **How it could work** (optional: detailed explanation)

### Example Feature Request
```
**Title**: Dark mode toggle for OLED screens

**What I want:**
Option to enable true black dark mode that uses #000000 instead of dark gray

**Why I want it:**
OLED screens save battery with true black. Better for eyes at night.

**How it could work:**
Add toggle in settings: "Dark mode" → "Standard" / "OLED" / "True Black"
```

**Response time**: 24-48 hours (discussion with community)

## ❓ Asking Questions

### Best Practices
- Search [FAQ.md](FAQ.md) first
- Be specific about what you're trying to do
- Include what you've already tried
- Provide screenshots if visual issue

### Example Question
```
**Title**: How do I add my MP3 files to Zenify?

**What I'm trying to do:**
Add my local music library (folder of MP3s) to Zenify

**What I've tried:**
- Looked for upload button (didn't find one)
- Checked settings (no local files option)

**Question:**
Is there a way to add local MP3 files? Or is streaming only?
```

**Response time**: 24-48 hours
